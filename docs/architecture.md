# Architecture

### Crypto

**circuits/zk.circom** - the circom file for our zero knowledge proof

**zk.js** - javascript functions for handling backend functions like verifying zk proofs, user log in, etc.

### Visuals

**index.html** - the main html which contains the contents of the website

**style.css** - the styling for the website

**script.js** - the javascript for the visual changes on the website
